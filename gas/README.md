# Google Apps Script 同期セットアップ手順

採集記録アプリからのデータを、あなたのGoogleドライブ上のスプレッドシートに
自動追記するためのセットアップです。完全無料で行えます。

## 1. スプレッドシートを新規作成する

1. [Google スプレッドシート](https://sheets.google.com) を開き、新しいスプレッドシートを作成する。
2. わかりやすい名前（例:「採集記録」）を付ける。

## 2. Apps Script エディタを開く

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を選択する。
2. デフォルトで開かれる `コード.gs`（または `Code.gs`）の内容を全て削除し、
   このリポジトリの `Code.gs` の内容を貼り付ける。
3. 上部の「保存」（フロッピーディスクのアイコン）をクリックする。

## 3. ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」をクリックする。
2. 「種類の選択」（歯車アイコン）から「ウェブアプリ」を選択する。
3. 設定:
   - 説明: 任意（例: 採集記録sync v1）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
     （「全員」を選んでも、URLを知っている人以外はアクセスできません。
     これはPWA側から認証なしでPOSTするために必要な設定です。）
4. 「デプロイ」をクリックする。
5. 初回は「承認が必要です」という画面が出ます。自分のGoogleアカウントを選び、
   「詳細」→「（プロジェクト名）に移動」→「許可」と進めてください
   （これは自作スクリプトなので安全です。Googleの警告は未検証アプリに対する
   標準的な確認です）。
6. デプロイ完了後に表示される **ウェブアプリのURL**（
   `https://script.google.com/macros/s/xxxxxxxx/exec` の形式）をコピーする。

## 4. アプリ側にURLを登録する

1. 採集記録アプリを開き、「設定」タブへ移動する。
2. 「Google スプレッドシート同期」の入力欄に、コピーしたURLを貼り付けて保存する。
3. 「一覧」タブの「今すぐ同期」を押して、正常に同期できるか確認する。
   スプレッドシートに `records` シートが自動作成され、そこに行が追加されていれば成功です。

## 5. コードを更新したときの再デプロイについて

`Code.gs` の内容を変更した場合、保存するだけでは反映されません。
「デプロイ」→「デプロイを管理」→ 既存のデプロイの鉛筆アイコン →
「バージョン」を「新バージョン」に変更 → 「デプロイ」を再度実行してください。
（URLは変わらないので、アプリ側の設定変更は不要です。)

## 仕様メモ

- 受信したレコードは `sample_id` をキーに重複チェックを行い、既に同じIDの行が
  あれば上書き更新、なければ新規追加します。これにより、アプリ側で記録後に
  ID・メモ・タグを編集した場合の再送信にも対応します。
- ヘッダー行は `records` シート作成時に自動で挿入されます。列を並べ替えたり
  削除したりすると同期が壊れるため、列の追加は右側に対してのみ行ってください。
- 位置情報の列（`lat`, `lon`）は十進数（度）です。Googleマップ等にそのまま
  貼り付けて確認できます。
