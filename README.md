# 採集記録アプリ

生物採集時の座標（十進数）・標高・時刻・サンプルIDをオフラインで記録し、
オンライン復帰時にGoogleスプレッドシートへ自動同期するPWA（Progressive Web App）です。

## 構成

```
collector-app/
├── app/                    # PWA本体（このフォルダをホスティングする）
│   ├── index.html          # 記録・一覧・設定の3タブ構成の画面
│   ├── style.css
│   ├── app.js               # 画面制御・GPS取得・イベント処理
│   ├── db.js                 # IndexedDBラッパー（records / tag_definitions / settings）
│   ├── sync.js                # Googleスプレッドシートへの同期キュー処理
│   ├── idlogic.js              # ID採番・整形ロジック（純粋関数・単体テスト対象）
│   ├── service-worker.js        # オフラインキャッシュ
│   ├── manifest.json             # PWAマニフェスト
│   └── icons/                     # ホーム画面アイコン
├── gas/
│   ├── Code.gs               # Google Apps Script（スプレッドシート受信側）
│   └── README.md              # GASセットアップ手順
└── test/                    # Node.js上でのテスト（unit + jsdom統合テスト、計61件）
```

## iPhone / Android へのインストール方法

このアプリはApp Store / Google Playを経由しない「ホーム画面に追加」方式のPWAです。
どこかにファイルをホスティングする必要があります（下記「ホスティング方法」参照）。

### iPhone（Safari）
1. ホスティングしたURLをSafariで開く。
2. 共有ボタン（□に↑）をタップ → 「ホーム画面に追加」を選択。
3. ホーム画面に追加されたアイコンから起動する（以降は独立したアプリのように動作する）。

### Android（Chrome）
1. ホスティングしたURLをChromeで開く。
2. メニュー（︙）→「ホーム画面に追加」または自動表示される「インストール」バナーをタップ。

## ホスティング方法（無料）

PWAは https（暗号化通信）で配信する必要があります（`localhost` は例外的に平文でも動作します）。
無料で使える静的ホスティング先の例:

- **GitHub Pages**: GitHubリポジトリの `app/` フォルダ内容をそのまま配置すればよい。個人用に非公開リポジトリでも設定可能。
- **Cloudflare Pages / Netlify / Vercel**: いずれも無料枠でHTML/CSS/JSの静的配信に対応。

`app/` フォルダの中身（`index.html` を含む）をそのままアップロードしてください。
ビルドツールは使用していないため、変換作業は不要です。

## Google スプレッドシート同期のセットアップ

`gas/README.md` の手順に従ってください。完了したら、アプリの「設定」タブで
発行されたウェブアプリURLを貼り付けて保存します。

## 使い方

1. アプリを開くと自動的にGPSの取得が始まります。画面上部に緯度・経度・
   標高・**取得精度（誤差半径）**が表示され、精度に応じて緑（良好）/黄（普通）/
   赤（低精度）で色分けされます。
2. コロニーなど特別な採集をした場合は、対応するタグボタンをタップしてから
   記録してください（IDの末尾に自動でサフィックスが付きます）。
3. 必要であればメモを入力し、「記録する」を押します。振動でフィードバックがあります。
4. 押し間違えた場合は「直前の1件を取り消す」で取り消せます。
5. 「一覧」タブで記録済みデータを確認・編集できます。行をタップすると
   ID・座標・タグ・メモを編集できるモーダルが開きます。
6. オンラインになると自動的にGoogleスプレッドシートへ同期されます。
   手動で同期したい場合は「一覧」タブの「今すぐ同期」を押してください。
7. 「設定」タブでは、タグの追加・削除、採集日の手動固定（深夜をまたぐ採集向け）、
   同期先URLの設定、全データのJSONバックアップ・インポートができます。

## 既知の制約と運用上の注意

- **バックグラウンド位置取得は行いません。** アプリを開いている間のみGPSを
  取得します。ホーム画面に戻したり画面をロックすると、次に開いたときに
  再度精度が安定するまで少し時間がかかることがあります。
- **iOSのSafari/PWAの制約により、画面を閉じた状態での位置情報取得はできません。**
  これは意図的な設計であり、常時追跡による電池消費を避けるためのものです。
- ブラウザのローカルストレージ（IndexedDB）は、端末のストレージが極端に
  逼迫した場合にOSにより削除されるリスクがあります。定期的に
  「設定」タブの「全データをJSONでエクスポート」でバックアップを取るか、
  Googleスプレッドシートへの同期を確実に行ってください。
- GPS精度が悪い場所（谷間・密林・室内等）では、必要に応じて一覧の編集モーダルから
  座標を手動修正できます。
- 複数人での採集を想定する場合、ID重複を避けるため採集者イニシャルなどを
  タグとして追加することをお勧めします。

## テストの実行方法

```bash
cd test
node test_idlogic.js                    # ID採番ロジックの単体テスト (16件)
node integration_test.js                # 記録フローの統合テスト (17件)
node integration_test_list_edit.js      # 一覧・編集・タグ設定の統合テスト (18件)
node integration_test_sync.js           # 同期キューの統合テスト (10件)
```

いずれも `npm install` （jsdom, fake-indexeddb）が事前に必要です。
